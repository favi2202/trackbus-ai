## Honest limits

The repository does not claim production accuracy or ROI. The hosted scenario
is visibly synthetic. Real acceptance requires approved representative footage,
held-out event labels, operating-category results, uptime, failure analysis, and
per-bus cost. Vision remains optional and does not perform facial recognition.

The final commit hash and exact command results are supplied in the engineering
handoff after the repository gate and remote push complete.
