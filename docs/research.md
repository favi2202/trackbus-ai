# Research notes

The v0.1.2 technical hypothesis is that a pretrained person detector, temporary
ByteTrack IDs, and two calibrated doorway zones can produce a useful baseline on
an overhead recorded video. This remains a hypothesis until evaluated on
representative, ethically collected footage from actual bus environments.

Future evaluation should report event-level entry/exit precision and recall,
absolute count error per door cycle, ID-switch behavior, processing speed, and
performance across crowding, lighting, and occlusion conditions.
