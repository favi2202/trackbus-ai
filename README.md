
# TrackBus

TrackBus is an AI-powered bus occupancy detection system.

## Vision

Provide real-time occupancy information for public transportation.

## Problem

Passengers don't know how crowded buses are before they arrive.

## Solution

Use overhead cameras and computer vision to estimate occupancy.

## Technologies (planned)

- Python
- OpenCV
- YOLO
- FastAPI
- PostgreSQL
- Docker
- GitHub Actions
